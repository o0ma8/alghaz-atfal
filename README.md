# لُغزي الصغير 🧩

موقع عربي تفاعلي لألعاب ألغاز تعليمية قصيرة للأطفال، مع نصائح للأمهات حول اللعب والتعلّم معًا.

## تشغيل الموقع محليًا
افتح `index.html` مباشرة في المتصفح. لا يحتاج الموقع إلى تثبيت حزم أو خدمات خارجية.

## نشره عبر GitHub Pages
1. افتح **Settings** في المستودع.
2. من القائمة الجانبية اختر **Pages**.
3. في **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.

الموقع لا يجمع بيانات الأطفال ولا يطلب تسجيلًا أو معلومات شخصية. الألعاب للترفيه والتعلّم العام، وليست تقييمًا أو تشخيصًا.
